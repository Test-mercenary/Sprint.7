# 🛴 Samokat API Tests (Sprint 7)

## 📌 О проекте

Автоматизированные API тесты для сервиса Самокат.  
Покрывают ключевые бизнес-сценарии работы с курьерами и заказами.

Тестирование реализовано на уровне REST API с использованием подхода Page Object (Client + Model).

---

## 🚀 Стек технологий

| Технология     | Назначение                    |
|----------------|------------------------------|
| Java 11        | Язык разработки              |
| Maven          | Сборка проекта               |
| JUnit 4        | Тестовый фреймворк           |
| REST Assured   | API тестирование             |
| Allure         | Генерация отчетов            |

---

## 🧪 Покрытые сценарии

### Курьеры
- ✅ Создание курьера
- ❌ Создание дубликата
- ❌ Создание без обязательных полей
- ✅ Авторизация курьера
- ❌ Негативные кейсы авторизации

### Заказы
- ✅ Создание заказа (параметризованные тесты)
- ✅ Получение списка заказов
